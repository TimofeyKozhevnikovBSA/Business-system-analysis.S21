## 🛠️ Мои навыки
- **Сбор требований:** Интервью, анкетирование, анализ документов, работа со стейкхолдерами.
- **Моделирование:** Построение декомпозиций (функциональная, объектная, процессная, событийная), луковичных диаграмм.
- **Документирование:** Составление глоссариев, каталогов источников информации, определение интересов и потребностей стейкхолдеров.
- **Инструменты:** Git, Markdown, draw.io, Miro, Excel, REST API (базовый), SQL (базовый).
